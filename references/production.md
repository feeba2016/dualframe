# 生产流程

## 环境与目录

Python 依赖见根目录 requirements.txt；ffmpeg/ffprobe 放在 PATH，FFmpeg 需支持 libass 和 libx264。manifest 的 font 指向本机支持中英文的字体，不依赖固定用户目录或其他项目的字体文件。

脚本可在任意工作目录运行，媒体和字体相对路径以 manifest 所在目录为基准。每轮独立目录，渲染默认在本轮 output/，不要同时写同一个输出目录。

```bash
python /path/to/dualframe/scripts/new_job.py --root /path/to/project --font /path/to/cjk-font.ttc
```

本工作流可独立于 MoneyPrinterTurbo 运行。真实发言不使用库存画面、合成配音或新增配乐替代。

## 原片检索与获取

1. 确认前只检索和检查网页、来源元数据，列出候选人物、时期、官方来源、日期性质和估计时长；收到本轮内容确认后才下载与制作。
2. 优先官方机构、本人或完整采访原片，核对发布账号、事件日期和人物身份。新闻转载可用于定位。拍摄日不可核实时，明确标注发布日期，不能把上传日写成事件发生日。
3. 本轮保存来源 URL、标题、账号、日期及性质、获取日期、原片时间码。可用 yt-dlp 获取元数据和字幕，随后选择高分辨率视频与原声音轨。只保留稳定来源链接，避免在交付或公开仓库中放临时 CDN 签名 URL、cookies 或凭据。
4. 下载后用 ffprobe 核实实际分辨率、时长、音轨。优先 1080p/4K 原片，根据人脸在原始画面中的位置逐条选择 crop，不能套上个任务的取景。旧素材低清时先寻找更高质量官方版本，无法找到则如实说明上限。

例如，已安装 yt-dlp 时先检查已确认来源：

```bash
yt-dlp --skip-download --write-info-json --write-auto-subs --sub-langs en --sub-format json3 -o 'source/%(id)s.%(ext)s' 'SOURCE_URL'
```

自动字幕只是定位参考。下载能力与站点支持取决于当前环境；不可把检索到的网页当作已经核实的原片，也不可承诺所有来源都能获取。

## 选段与字幕

- 优先选两段各自连续、语义完整的发言，再按自然停顿分成上下交替的轮次。总时长接近比每轮秒数一致更重要；同一人物跨时期也按两个来源处理。
- 听看原片前后文，确认回答确由目标人物说出；团访不能把其他成员的发言算进目标人物时长。某侧可用原声太短时，缩短整体，或说明需调整来源。
- 起始、切换和末尾都要查看。有记者切镜或远景时，调整选段或取景，不以静态人像掩盖仍在讲话的原片。
- 完整句末保留尾音与自然停顿，避开下一句话首词。逐词时间码、静音检测只能辅助定位；ends_after 记录实际讲完的完整意思，boundary_reviewed 只有核对后才设 true。
- 中文忠实翻译，英文忠实对应原声。原声非英语时，英文也应翻译，并在来源说明注明原语种。保留专名、否定、条件和限定，不加评论。
- cue 按阅读单元划分，中文最多两行、英文最多三行。过长时按实际词时码拆分；hold 文本保留上一轮末尾完整句意。
- 本地素材从原片中途开始时，用 source_offset 记录偏移；原片时间 = 本地时间 + 偏移。多镜头预处理保留详细映射，不能给已拼接的非连续素材虚构单一偏移。
- 渲染器不改速；音频仅补齐尾部容器时长并编码为 AAC。默认不做音量归一化。除非用户要求，避免改动原始表达与音色。

## QA 与交付

先运行 --check-only，再渲染。查看 qa/report.json、contact sheet 和长字幕画面，逐轮检查人物、字幕、日期、暂停帧及起止切点。必要时另提取每轮起始/末尾帧和最终音轨复核。

自动验证检查输出尺寸/帧率、SRT 时序、两次抽样画面的运动与静止、全片解码。近乎静止的真实采访也可能触发 needs_review；此时回看原片与成片，不能为了通过而添加假运动。可保存人工复核依据。默认渲染器会在 needs_review 时非零退出，产物保留供检查，不能因此宣称通过。

本轮保存：用户确认记录、manifest、必要原片、MP4、SRT、timeline、来源说明和 QA 记录。完成交付后才更新 视频任务/状态.json 为 completed，填写输出路径和完成时间。等待下次用户启动，不循环制作。
